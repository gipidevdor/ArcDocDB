Documentation website and build tools
-------------------------------------
The database has no external Lisp library dependencies beyond SBCL contribs.
This statement does not exclude the Unicode data license or the separate
documentation toolchain.

The manual sends Mermaid 11.12.1 and its bundled components to browsers.
Complete browser notices: tools/pages/third-party-notices.txt.
Versioned component inventory: tools/pages/third-party-notices.lisp.
DOMPurify's Apache-2.0 alternative is selected for this distribution; its
original dual-license notice is preserved. Do not remove the included notices.

The documentation build uses additional Common Lisp tools, including tools
under LGPL/LLGPL terms. They are not linked into the database or delivered as
browser implementations by this build. Do not redistribute _build/ caches,
toolchain source trees or build images as if they were solely ArcDocDB code.
Review and preserve their individual terms when distributing those materials.

See docs/legal/distribution.md for artifact-specific distribution requirements
and docs/legal/review-2026-10-31.md for the review scope and unresolved matters.
