# Privacy and local storage

This notice describes the ArcDocDB documentation site at
`https://gipidevdor.github.io/ArcDocDB/`. The publisher and project contact are
listed in [publication information](README.md). It describes this edition's
behavior; it does not describe a deployed ArcDocDB database or an NNTP service.

## What the site does

The site serves static documentation. Its own code does not add analytics,
advertising, visitor profiles, fingerprinting, embedded social widgets or
tracking cookies. It does not provide accounts, a contact form or a database
into which visitors submit information.

Scripts, images and stylesheets are served with the manual. Fonts come from
your device. Diagram rendering does not request a third-party CDN at reading
time. External links lead to other services only when you follow them; those
services have their own privacy notices.

## Search

Search downloads a static index from the same site and matches your words in
your browser. The site code does not put search words into a URL, send them in a
network request or store a search history. The controls are disabled until the
JavaScript handlers are ready, and the page policy prohibits form submissions.
Without JavaScript, use the complete document index.

Requesting the index and following a result still make ordinary hosting
requests. Browser history, extensions, accessibility software and operating
system behavior remain under your control.

## Appearance preference

Choosing **Light** or **Dark** stores that choice in your browser's local storage
under `arcdocdb-theme`. It contains only the appearance setting, not an identifier
or a browsing history. The site does not send that value to a service.

Choosing **System** removes the stored value. You can also remove it through
your browser's controls for site data. Browser local storage has no automatic
expiry set by this edition; it remains until removed by you or your browser.
If storage is unavailable, the page remains readable and the appearance control
works for the current page.

This is a user-requested display preference, with no analytics or profiling
purpose. The Italian Data Protection Authority's
[cookie and tracking guidelines](https://www.garanteprivacy.it/home/docweb/-/docweb-display/docweb/9677876)
distinguish technical functions from tracking and explain when information can
be given without a consent banner. This edition uses a notice rather than a
tracking-consent interface because it adds no optional tracking tools.

## GitHub Pages hosting

GitHub states that it logs and stores visitors' IP addresses for security
purposes when a GitHub Pages site is visited, including visits made without
signing in. See [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

GitHub's [General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
describes its processing purposes, legal bases where applicable, recipients,
international transfers, retention criteria and privacy rights. The ArcDocDB
site code does not set GitHub's hosting-log retention period or provide its own
visitor-log collection endpoint. No fixed hosting retention period is promised
here.

For questions or rights requests about GitHub's processing, use the
[privacy contact in that statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement#contact-us).
Depending on the law that applies to you, rights may include access, correction,
deletion, restriction, objection or portability, and the right to complain to a
supervisory authority. The relevant provider explains the conditions and handling
of those requests.

## Contacting the project

The project's published contact is [@gipidevdor on GitHub](https://github.com/gipidevdor).
Use the project's issue tracker for editorial corrections and public questions.
GitHub receives the information you submit through that service. Send only what
is needed for the request. Issues and comments are public; GitHub's privacy
terms apply to that service.
Use the [project contact information](README.md#contact-and-corrections) for a
site-specific question and identify the page concerned without sending passwords,
private database contents or other confidential data.

This notice must be reviewed before adding analytics, remote embeds, new
storage keys, forms or other visitor-data collection. The
[editorial policy](../editorial-policy.md) records the publication checks and
their limits.
