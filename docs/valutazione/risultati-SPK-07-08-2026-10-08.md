# SPK-07 and SPK-08 — progress on 2026-10-08

> **Proposal** — Local Phase 0 evidence. Models and kernels are
> experiments: they do not qualify the engine or close the architectural gate.

<a id="provenienza"></a>

## Provenance

Isolated checkout starting from `62267c9`, Apple M4, 16 GiB, Darwin 27.0.0
ARM64, SBCL 2.6.9, `safety 3`. The three independent modules were developed
in parallel; the parent integrates the SIMD kernel and runners. Benchmarks run
serially; load from other machine activities remains
uncontrolled. Clock resolution is 1 µs.

The [catalog](https://github.com/gpicchiarelli/ArcDocDB/blob/13c2eec90a7a80f97f3bd9ded6b62abd75b7cf78/spikes/results/2026-10-08-avanzamento/catalogo.lisp)
retains sources, commands, bounds, decoded results, and original output,
including errors. Reports are data read with `*read-eval*=nil`, never code.
Portable fingerprint evidence retains the complete original text
and declares conversion of only package symbols to strings.
The new runner directly produces this self-contained representation.

<a id="spk-07-due-lettori-e-due-slot"></a>

## SPK-07: two readers and two slots

[Method](../../spikes/SPK-07-protocols/metodo-seqlock-readers.md) and
[full campaign](https://github.com/gpicchiarelli/ArcDocDB/blob/13c2eec90a7a80f97f3bd9ded6b62abd75b7cf78/spikes/results/2026-10-08-avanzamento/seqlock-readers-campaign-portable.lisp).

One writer serially updates two slots; two readers may observe the
same or different slots. Each reader has two attempts and then writer
service. The oracle uses an independent logical history and checks the accepted
tuple at the recorded read point, as well as hits and misses.

| Check | Observed result |
|---|---:|
| Correct graphs | 8 |
| Correct states / edges | 28,434 / 65,096 |
| Tuple / query checks | 8,240 / 24,720 |
| Positive witnesses, including retry and fallback for both | 192 |
| Mutants detected with specific witness | 28 |
| Maximum states/graph / ceiling | 5,961 / 200,000 |

Rank increases along every edge and all correct states are completable.
This is a finite SC result: atomic location, one update per
slot, one read per reader, no wrap. It does not prove weak memory, hardware
barriers, cross-slot snapshots, or maximum times with real scheduling.

Seven attempts: one initial syntax error, three successful CHECKs, three
expected failures at the 32-state ceiling. Attempt 005 also retains a
condition-decoding error in the recorder, recovered and declared
in the catalog. The 13 successful compilations produce no warnings.

<a id="spk-07-crash-sui-byte"></a>

## SPK-07: byte-level crashes

[Method](../../spikes/SPK-07-protocols/metodo-byte-crash.md) and
[final record](https://github.com/gpicchiarelli/ArcDocDB/blob/13c2eec90a7a80f97f3bd9ded6b62abd75b7cf78/spikes/results/2026-10-08-avanzamento/byte-crash-attempt-10.lisp).

Independent little-endian packing and bitwise CRC produce v1/v2 fixtures,
ordinary and prepared/OUTCOME. The real verifier checks batches; expected
history is declared separately. For each buffer all
cuts and single-bit alterations are exhausted. The confirmed frontier is explicit
external proof in the model.

| Check | Observed result |
|---|---:|
| Fixtures / main cases | 16 / 49,120 |
| Identity / truncations / single-bit alterations | 16 / 5,456 / 43,648 |
| Complete / tails / confirmed damage rejected | 16 / 25,092 / 24,012 |
| Recovery / checkpoints performed | 655,997 / 3,760,830 |
| Equivalent interruptions and restarts | 303,432 each |
| Mutants / SEAL semantic checks / final flush | 3 / 5 / 1 |

Bytes remain unchanged even after interruption and rejection. Eight attempts
fail as expected from budget exhaustion. Attempt 03 is
preliminary and remains retained: review corrected the relationship between
external frontier and SEAL-declared frontier. Attempt 10 is the final test.
The 73 strict compilations succeed without warnings.

The final flush without a subsequent witness remains indistinguishable from the
log alone: the witness uses equal bytes and two external frontier facts, obtaining
tail or FAULTED. Real filesystem, flush/rename,
segment headers, DECISION, manifest, simultaneous faults, or complete engine
recovery are not tested. A single-bit check does not prove absence of CRC collisions.

<a id="spk-08-maschere-esatte-e-codice-generato"></a>

## SPK-08: exact masks and generated code

[Scalar/SWAR method](../../spikes/SPK-08-generated-code/metodo-impronte.md),
[SIMD method](../../spikes/SPK-08-generated-code/metodo-simd.md),
[integrated CHECK](https://github.com/gpicchiarelli/ArcDocDB/blob/13c2eec90a7a80f97f3bd9ded6b62abd75b7cf78/spikes/results/2026-10-08-avanzamento/integrated-check.lisp).

Four kernels produce a 16-bit mask, one bit per byte equal
to fingerprint 0–127. SWAR uses the exact formula without borrowing between lanes; the
subtraction-based mutant is disproved by 28 witnesses. CHECK runs
3,035,203 groups, 12,140,812 comparisons, and 77 negative checks. It includes all
adjacent byte pairs and all u16 masks. An initial load
was rejected for style-warning; three subsequent CHECKs succeeded.

The native kernel uses SBCL contrib `sb-simd`, checks window and query
before load, and retains `safety 3`. On ARM64, disassembly shows NEON
load and vector comparison. It passes 589,824 comparisons, 16 immutability
checks, and four rejections. The SSE2 path is present but not run
on this machine; bitmaps and checksums are not part of this campaign.

## Serial benchmark

Command: `sbcl --noinform --no-userinit --no-sysinit --script tools/run-spikes.lisp --bench SPK-08`.
[Original record](https://github.com/gpicchiarelli/ArcDocDB/blob/13c2eec90a7a80f97f3bd9ded6b62abd75b7cf78/spikes/results/2026-10-08-avanzamento/spk08-benchmark.lisp)
and [derived statistics](https://github.com/gpicchiarelli/ArcDocDB/blob/13c2eec90a7a80f97f3bd9ded6b62abd75b7cf78/spikes/results/2026-10-08-avanzamento/spk08-summary.lisp).
There are 70 samples, five replicates/cell, **128,450,560 measured groups**.
AB/BA order is alternated; checksums validated, fixtures and reports excluded from
timing. All cycles report zero observed bytes consed.

### Scalar/SWAR

1,024 rows/dataset, 64 passes/sample: 65,536 groups per sample,
40 samples. Compared pairs read the same data and queries.

| Dataset | Representation | Scalar, median ns/group | SWAR, median ns/group |
|---|---|---:|---:|
| Mixed | bytes, packing included | 21.713 | 17.319 |
| Adversarial | bytes, packing included | 23.254 | 17.288 |
| Mixed | two preprepared u64s | 17.563 | 4.745 |
| Adversarial | two preprepared u64s | 19.165 | 4.791 |

### NEON

16,384 groups/dataset, 256 passes: 4,194,304 groups/sample, 30 samples.
Fixed query 42; 256 KiB array. This matrix uses different data from
SWAR: the two matrices' timings are not a SWAR-versus-NEON comparison.

| Dataset | Scalar, median ns/group | NEON, median ns/group | Scalar range | NEON range |
|---|---:|---:|---|---|
| Mixed | 18.381 | 2.164 | 18.354–18.851 | 2.164–2.165 |
| All hits | 12.680 | 2.168 | 12.664–12.756 | 2.161–2.171 |
| Special, no hits | 12.349 | 2.165 | 12.340–18.078 | 2.160–2.165 |

The range also retains slower scalar replicates. The counter's positive
control records 23,904 observed bytes consed while constructing an
array with 131,072-byte payload; this is not an exact measurement of its size.
Observed zero in cycles, together with disassembly, supports local feasibility
of the typed path: it is not a guarantee for boxed calls or
every SBCL configuration. Data is synthetic and cache-resident; these
measurements are not database GET/s, P99, seqlock costs, or CPU comparisons.

<a id="raccomandazione-e-lavoro-restante"></a>

## Recommendation and remaining work

> **Proposal** — Retain these kernels as experimental references.
> Before choosing one for the index, measure variable queries,
> actual layout, concurrent reads, and beyond-cache footprint on the same dataset;
> run the x86-64 path and reference platform. Selection
> must retain range checks and read validation.

The SPK-07 suite keeps the gate open for complete weak memory, real-file
crashes, and fault injection. No engine requirement changes status
based on these results.
